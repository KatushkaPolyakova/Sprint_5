Проект автоматизации тестирования для  приложения "Доска".
Основа для написания автотестов- фреймворк Selenium + pytest для сценариев:
- регистрация пользователя (валидная, невалидный email, существующий пользователь);
- авторизация и выход;
- создание объявления (авторизованный / неавторизованный пользователь).
  
Установить зависимости — pip install selenium
Команда для запуска -  pytest -v
